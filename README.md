# Discourse Mailto Reply Plugin

This plugin adds email reply functionality to Discourse posts by generating mailto: links that open the user's default email client with a pre-composed reply.

## Features

- 📧 Opens default email client with pre-filled reply
- 🔗 Includes proper email threading headers
- 💬 Quotes original message content
- ⚙️ Configurable via admin settings
- 📱 Mobile-responsive design
- 🌐 Supports multiple email clients (Outlook, Apple Mail, Thunderbird, Gmail)
